# DMR Curve Studio

DMR 3.20 / VX5300 `.PLR` 温度曲线可视化编辑器。

## 直接使用

双击：

```text
启动DMR曲线编辑器.cmd
```

浏览器会打开 `http://127.0.0.1:17378`。运行界面不需要 Python，也不需要安装 npm 依赖；项目已经包含离线 Excel 解析器。

推荐流程：

1. 在 DMR 打开原始 `.PLR`，导出同源 `.xls`；
2. 在 Curve Studio 同时载入 `.PLR + .xls`；
3. 选中不合格时段，使用“真实燃烧合规修复”或其他批量工具；
4. 录入升温、保温或降温客户要求并校验；
5. 校验通过后导出客户 PNG 和 `_edited.PLR`；
6. 用 DMR 打开新 PLR，再导出 Excel；
7. 点击“载入 DMR 回读 Excel”完成逐点闭环验证。

## 已实现

- 通道数量不写死：当前 VX5300 样本默认 9 通道，扩展记录结构可配置 16 个及更多温度通道；
- 支持“仅当前”“全部”以及任意勾选多个通道叠加展示；展示通道与编辑通道分离，避免误改；
- 可把全部已展示通道作为一次协同编辑范围，共享燃烧趋势和随机波动，同时保留各测点温差与少量独立响应；
- 可开启“协同绘制”，直接在图上点选或拖动画线；当前通道的手工温差会同步作用于全部展示通道；
- 环形缓冲区自动对齐（真实样本物理起点 530）；
- 鼠标拖动绘制、逐点输入；
- 偏移、恒温、线性、限幅、平滑、正弦、单位时间温差限制；
- 真实燃烧波动修复：多时间尺度相关噪声、慢漂移、弱变周期成分、非对称燃料脉冲和原曲线残差融合，固定种子可复现；
- 提供真实样本升温、保温、降温余热、原曲线优先、强扰动弱周期五组预设；
- 升温阶段每小时升温上限、保温阶段滚动窗口温差上限、降温阶段每小时降温上限；
- 仅修复违规窗口及过渡区，未选时间段保持不变；
- 客户要求多规则录入、逐规则校验和 PLR/PNG 导出门禁；
- DMR 风格 `1h / 4h / 8h / 12h / 24h` 时间轴、滚轮中心缩放、`Shift+滚轮` 平移和拖动画布；
- 撤销/重做；
- PLR 字节级兼容检查；
- 高温通道按 `uint16` 原始字处理，可安全跨越传统 `int16` 的 32767 分界；
- PLR、PNG、CSV、项目 JSON 导出；
- 多通道 PNG 带固定颜色图例、当前编辑通道和原始值虚线标识；16 个及更多通道时图例自动换行并扩展图片高度；
- DMR 回读 Excel 验证；
- DMR 3.20.0 单点、线性、平滑、单通道真实燃烧、多通道协同燃烧五类真实闭环回归。

## 真实燃烧合规修复

1. 用左右滑块选中客户判定为不合格的局部时间段；
2. 处理方式选择“真实燃烧合规修复（推荐）”；
3. 选择“升温阶段”“保温阶段”或“降温阶段”；
4. 先选择真实波动预设，再填写 `60 min` 窗口和对应客户限值；
5. 保持“只修复违规窗口”和“同时加入客户验收要求”勾选；
6. 应用后在“客户验收要求”区域检查时间、通道和限值；
7. 点击“校验客户要求”。全部通过后才能导出 PLR 和客户 PNG。

同一随机种子和参数会产生完全相同的修复结果；更换种子可获得另一条仍满足限制的非规律曲线。项目 JSON 会保存目标温度和全部客户要求。

真实 `DAT0131` 样本分析得到：升温段去趋势残差标准差约 `1.9～2.9℃`，保温段约 `1.4～1.7℃`，自然降温段约 `4.8℃`；降温段惯性明显更长。预设据此调整波动强度、原曲线保留比例、共同波动比例、趋势同步比例、相关时间和扰动频率。默认周期成分比例仅为 `0.05～0.10`，不再由明显正弦波主导。

推荐直接选择：

- 升温：`真实样本·升温（推荐）`；
- 保温：`真实样本·保温稳态`；
- 降温：`真实样本·降温余热`；
- 原曲线质量较好：`原曲线优先·轻修复`；
- 原曲线过于平滑或规律：`强扰动·弱周期`。

## 多通道共同波动调整

1. 在“叠加展示通道”中勾选需要共同修复的测温通道；
2. 批量模式选择“真实燃烧合规修复”；
3. “应用通道范围”选择“全部已展示通道（共同调整）”；
4. 设置共同波动比例、趋势同步比例、通道响应差异和共同温度调整；
5. 点击“协同修复 N 个已展示通道”。

算法只生成一套共同燃烧驱动，再叠加各通道原有温差、测点位置差异和少量独立噪声。因此各通道升降节奏高度一致，但不会机械地完全重合。任一通道出现违规时可使用联合违规时间掩码，同一时段内的已选通道一起修复；系统同时为每个通道生成独立客户验收规则。

### 图上手动协同编辑

1. 叠加显示需要联动的通道，并选择一个通道作为当前编辑基准；
2. 点击图表右上角“协同绘制：关”，切换为“协同绘制：N通道”；
3. 在图上单击某个时间点，可同时修改 N 个通道该点的温度；
4. 在图上连续拖动，可像单通道绘制一样共同修改一段波动趋势；
5. 一次手势作为一条撤销记录，可整体撤销/重做。

协同绘制使用相同温差而不是相同绝对温度。例如当前通道某点提高 3℃，其他已展示通道也分别在自身原温度上提高 3℃，因此测点之间原有温差不会被抹平。

### 16 通道及以上设备

在载入区域展开“高级格式参数”，填写设备实际的“单条记录字节”和“温度通道数”。连续 16 通道至少需要容纳 `field_00～field_16`，即单条记录至少 34 字节；软件会在解析前校验通道是否超出记录边界，避免写错非温度字段。

界面通道复选区和图例支持自动换行；通道10以后使用不重复的扩展颜色。悬浮提示会根据通道数量自动分成多列，PNG 图例也会自动换行并增加画布高度，不会覆盖曲线区域。当前 24 字节真实样本仍保持只编辑已验证的通道01～09。
