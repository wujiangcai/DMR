# DMR Curve Studio

DMR 3.20 / VX5300 `.PLR` 温度曲线可视化编辑器。

## 直接使用

双击：

```text
启动DMR曲线编辑器.cmd
```

浏览器会打开 `http://127.0.0.1:17378`。运行界面不需要 Python，也不需要安装 npm 依赖；项目已经包含离线 Excel 解析器。

推荐流程：

1. 在 DMR 打开原始 `.PLR`，导出同源 `.xls`；
2. 在 Curve Studio 同时载入 `.PLR + .xls`；
3. 选中不合格时段，使用“真实燃烧合规修复”或其他批量工具；
4. 录入升温/保温客户要求并校验；
5. 校验通过后导出客户 PNG 和 `_edited.PLR`；
6. 用 DMR 打开新 PLR，再导出 Excel；
7. 点击“载入 DMR 回读 Excel”完成逐点闭环验证。

## 真实燃烧合规修复

1. 用左右滑块选中客户判定为不合格的局部时间段；
2. 处理方式选择“真实燃烧合规修复（推荐）”；
3. 选择“升温阶段”或“保温阶段”；
4. 填写 `60 min` 窗口和客户限值（默认 `5℃/h` 或 `5℃`）；
5. 保持“只修复违规窗口”和“同时加入客户验收要求”勾选；
6. 应用后在“客户验收要求”区域检查时间、通道和限值；
7. 点击“校验客户要求”。全部通过后才能导出 PLR 和客户 PNG。

同一随机种子和参数会产生完全相同的修复结果；更换种子可获得另一条仍满足限制的非规律曲线。项目 JSON 会保存目标温度和全部客户要求。
